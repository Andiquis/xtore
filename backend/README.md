<h1 align="center">Backend del Proyecto Xtore</h1>

## Descripción
 
- Framework utilizado: NestJS (TypeScript).

## Configuración del Proyecto

- Instalar dependencias:
  ```bash
  pnpm install
  ```

## Compilación y Ejecución

- Modo desarrollo:
  ```bash
  pnpm run start
  ```
- Modo observación:
  ```bash
  pnpm run start:dev
  ```
- Modo producción:
  ```bash
  pnpm run start:prod
  ```

## Pruebas

- Pruebas unitarias:
  ```bash
  pnpm run test
  ```
- Pruebas e2e:
  ```bash
  pnpm run test:e2e
  ```
- Cobertura de pruebas:
  ```bash
  pnpm run test:cov
  ```

## Despliegue

- Pasos básicos para despliegue:
  ```bash
  pnpm install -g @nestjs/mau
  mau deploy
  ```
